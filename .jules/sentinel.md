## 2025-05-14 - Fix path traversal in smolvm sandbox arguments
**Vulnerability:** The sandbox startup script (`sandbox/scripts/run-agent.sh`) accepted unvalidated inputs for `ALLOWLIST`, `NAME`, and `--config` which could be manipulated for path traversal or option injection. Specifically, `--config` allowed mounting directories to arbitrary paths in the microVM via `VOL_ARGS+=(-v "$p:/home/agent/.pi/agent/$name:rw")`.
**Learning:** Shell scripts taking user inputs and mapping them to paths, machine names or volume mount destinations without strict validation are prone to path traversal. In this case, `smolvm` runs within a secure environment, but providing it with malicious input arguments compromises that boundary by writing over sensitive paths within the guest OS or bypassing sandbox constraints.
**Prevention:** Always validate shell script arguments using pattern matching (`case` statements rejecting `*/*`, `*..*`, and `-*`) before interpolating them into commands or paths. Do not trust inputs even in developer tools or sandbox wrappers.
